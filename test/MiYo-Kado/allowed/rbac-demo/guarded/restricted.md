# Restricted

This note is the whole point of the fixture: give it a **more-specific**,
read-only rule in your test key (`allowed/rbac-demo/guarded/restricted.md`). It
then resolves differently from its siblings, so renaming `guarded/` would move it
out from under that rule — which the neutrality guard refuses.
